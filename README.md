## 👋 About Me

I'm a **Software Engineer focused on Java backend development**, designing APIs, authentication flows, and service integrations. I enjoy turning business requirements into maintainable services, debugging integration issues, and learning how distributed systems behave in production.

- 🔭 **Core focus:** Java, Spring Boot, REST APIs, and microservices.
- 🔐 **Security & identity:** SAML 2.0 / OpenSAML, JWT, Spring Security, and SSO integrations.
- ⚡ **Event-driven systems:** Apache Kafka, producers, consumers, and asynchronous workflows.
- 🗃️ **Data:** PostgreSQL, MySQL, Redis, and Spring Data JPA.
- 🧰 **Engineering tools:** Git, Gradle, Docker, AWS fundamentals, and CI/CD concepts.
- 🌱 **Currently sharpening:** system design, reliability, testing, and production debugging.

> I value clear APIs, thoughtful design, observability, and code that the next engineer can understand.
